# 阅读体验与视觉优化 · 2026-09-13

本次聚焦开源项目的浏览与中文阅读。保留现有 FastAPI、静态前端与本地数据，基于工作区已有的改动继续完善。

## 设计计划

- 色彩：银灰画布 `#f4f6fa`、白色阅读面 `#ffffff`、深蓝墨色 `#253142`、正文灰蓝 `#4c5b70`、操作蓝 `#315f9f`、速览深蓝 `#263e53`；分类继续使用已有固定配色。
- 字体：中文使用本地苹方／微软雅黑，界面使用 Segoe UI Variable；仓库名称使用本地 Bahnschrift，回退到系统字体。标题、正文、元信息分别承担定位、阅读、辅助判断的职责。
- 布局：保持居中的开放双列项目库，统一卡片底部操作的对齐；桌面分类栏随阅读固定。长摘要提供独立、限宽、可调整字号的阅读窗口。
- 原则：把视觉重点留给真实仓库名称与项目内容；不引入外部字体、装饰图片或持续动画。短文直接浏览，长文舒展阅读。

```
顶部导航              发现 / 推荐 / 收藏              操作
页面标题与说明                         搜索
分类                              筛选 / 排序 / 视图
重点项目介绍                      真实 README 速览
项目 / 介绍 / 元信息               项目 / 介绍 / 元信息
操作                               操作

阅读窗口
项目阅读                         字号 / 关闭
                项目名称与作者
                完整简介
                中文摘要（限宽、分段）
查看仓库                                  问 AI
```

方案复核：不增加与项目无关的宣传区和指标区；在现有分类色与页面结构上调整文字、留白、材质和交互，保持这个工具的内容密度。专注阅读补足双列布局不适合长文的问题。

## 实施与验证

### 实际变更

- 浏览页调整标题字体、正文行距、元信息字号和留白。普通卡片按行对齐底部操作；展开摘要时恢复自然高度，避免旁边的卡片出现大片空白。
- 重点项目的速览采用深蓝阅读面，真实 README 内容成为视觉重点。保留分类标识和浅色／深色主题；手机端收起重复速览，将阅读入口提前。
- 新增“阅读项目”窗口，完整展示项目介绍与中文摘要，正文宽度上限为 672px，提供 17px／20px 两档字号并记住选择；原文介绍可按需展开。
- 阅读窗口保留 GitHub 与项目问答入口；问答关闭后返回阅读窗口，阅读窗口关闭后恢复项目库位置和触发按钮焦点。内容单独滚动，顶部控制与底部操作保持可见。
- 摘要支持标题、加粗、行内代码、列表和段落。处理顺序保持先转义远端文本、再加入受控的本地格式。
- 桌面端分类与筛选栏随阅读固定。没有增加前端依赖、远程字体或装饰图片。

新增阅读呈现模块为 `static/js/reader.mjs`；现有页面事件仍在 `app.js` 中接入。这次没有修改后端或实际收藏数据。

### 验证结果

- Node 检查 **34 项通过**，包含 6 项新增阅读测试，覆盖完整内容、缺失翻译、阅读时长、Markdown 格式与恶意远端文本。
- 本机 Chromium 独立会话的 **11 组浏览器检查通过**：打开阅读、焦点与背景滚动、字号记忆、刷新后偏好、原文介绍、问答返回、行内摘要、手机导航、主题与列表切换、固定筛选栏、搜索空状态。
- 验证 **320、390、640、768、880、1024、1280、1920px** 八种宽度。项目库和大字阅读窗口均未出现横向溢出；窗口底部操作没有被裁切。
- 查看了浅色首页、深色首页、紧凑列表、桌面阅读与手机阅读截图；深浅主题速览文字对比度检查通过，浏览器没有未捕获异常。
- `app.js`、`cards.mjs`、`reader.mjs`、`sanitize.mjs` 语法检查和 `git diff --check` 通过。

浏览器检查连接现有本地服务，使用独立会话保存显示偏好。为稳定截图，头像请求在测试会话中使用现有字母回退；没有触发真实模型问答或更改收藏。截图与浏览器报告保存在 `tmp-reading-20260913/verified/`。

静态文件由现有 Docker 挂载直接提供，刷新 `http://localhost:8098` 即可看到新版，无需重建镜像。
