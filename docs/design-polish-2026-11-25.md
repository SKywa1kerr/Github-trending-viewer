# 体验打磨（2026-11-25）

在 11-24 的 Apple 式版式上做一轮体验打磨：不换视觉方向，补齐“状态可恢复、操作可撤销、阅读不中断、手机更快看到项目”。

## 参考的设计技能

| 技能 | 用途 | 本次取用 |
| --- | --- | --- |
| Anthropic `frontend-design` | 定方向：明确的审美立场、字体与色彩角色 | 保持现有方向，只做克制的细节修整 |
| Vercel Web Interface Guidelines（`web-design-guidelines`） | 逐条可核对的交互规范 | 视图状态进 URL、破坏性操作可撤销、`theme-color` 与页面底色一致、弹层 `overscroll-behavior` |
| `impeccable`（Paul Bakaus） | 以 `polish`/`harden`/`adapt`/`audit` 等命令词分步迭代，附确定性反模式检测 | 按 polish → adapt → harden 的顺序组织本轮；未安装其钩子 |
| 本地 `design-taste-frontend` | 截图脚本与渲染后复查 | 改前改后截图对比、溢出与脚本错误检查 |

`impeccable` 的钩子会在模型审批之外运行并下载二进制，装之前先看一遍；本项目没有引入。

## 改动

- **地址栏即视图**：分类、搜索词、搜索范围、语言、Star 门槛、排序写入查询参数（`?view=ai&sort=stars_gained`）。刷新、书签、前进后退都能回到同一列表；切换分类和搜索范围记入历史，输入与筛选只替换当前记录。未知参数一律回落到默认值。
- **取消收藏可撤销**：提示条带“撤销”，停留 6 秒；在收藏页撤销后列表会恢复。
- **阅读器连读**：工具栏新增上一个／下一个，支持 ← →；读到已加载列表末尾时自动取下一页。
- **首屏主题不闪**：`/js/theme.js` 在首次绘制前应用已保存的主题和强调色，并同步 `theme-color`。
- **概况四项同构**：数据新鲜度由一句话改为“数字 + 单位”（`12` `小时前更新`），与另外三项同一基线。
- **骨架屏贴合版式**：占位块按卡片结构（头像、名称、正文、页脚）绘制，首页保留首推位，列表视图用矮行。
- **手机首屏**：收紧标题、概况与间距，分类图例改为单行横向滑动（右缘渐隐）。390×844 下首张卡片顶边由约 780px 上移到 649px。阅读器工具栏在手机上只保留操作：左侧翻页，右侧字号与关闭。

## 验证

- `node --test tests/*.mjs`：34 项通过（新增地址参数往返与非法值回落）。
- 真实浏览器脚本检查 14 项全部通过：首屏主题、地址写入与后退、深链接恢复、阅读器按钮与方向键、跨页连读、撤销收藏（检查后收藏数恢复原值）、无脚本错误。
- 桌面 1440、平板 768、手机 390 的浅色／深色截图复查，无横向溢出。

## 已知限制

- 手机分类图例一屏显示三项半，第四项需横滑；390 宽放不下四项完整文字。
- 地址参数不含显示方式、主题等个人偏好，它们仍保存在浏览器本地。
