项目已具备完整的个人开源项目发现流程，现有 FastAPI、SQLite 和原生 JavaScript 架构适合当前规模。此次优先处理数据正确性与失败恢复，并保留工作区原有的界面、筛选和模块拆分改动。

## 当前结构与运行情况

检查时本地服务位于 `http://localhost:8098`，包含 345 个项目、2 个收藏、4 个分类和 25 种语言。345 个项目的翻译状态均为完成，最近一次抓取为北京时间 2026-09-12 08:00:10。

| 模块 | 主要职责 |
| --- | --- |
| `app/main.py`、`app/scheduler.py` | 启动数据库、恢复翻译队列、安排每日抓取与定时重试 |
| `app/scraper.py`、`app/github_client.py` | 获取 Trending、分类话题和关注关键词结果，保存项目与 Star 历史 |
| `app/translator.py`、`app/ai_client.py` | 翻译排队、并发和频率控制、重试与模型请求 |
| `app/database.py`、`app/state_store.py` | SQLite 表结构、WAL 和持久化运行状态 |
| `app/routers/` | 列表、筛选、收藏、推荐、流式问答和诊断接口 |
| `static/js/app.js`、`library.mjs`、`cards.mjs`、`sanitize.mjs` | 页面状态与事件、公共逻辑、卡片呈现和文本转义 |

抓取后先保存项目、启动翻译工作任务并计算评分；前端通过状态轮询更新页面。推荐先根据收藏的标签和语言筛选候选，再由模型排序，结果按收藏集合缓存 24 小时。

## 本次已修复

| 问题与复现 | 修改后的行为 |
| --- | --- |
| GitHub 查询直接拼接 URL，`language:C++` 被解析成带空格的查询，`C#`、`R&D` 被截断 | 使用标准 URL 参数编码，保留特殊字符和中文 |
| 不完整的 Trending 数据覆盖已保存的更新时间；标签请求失败被转换为空标签 | 未知元数据保留已有值；明确返回的空标签仍可正常清空旧标签 |
| 模型推荐包含空值、错误字段类型、无效分数、未知仓库或重复仓库时，出现 500、空推荐或重复卡片 | 写入前验证字段、分数和候选身份，去重后取最多 10 项；全部无效时回退到标签与语言推荐，并正常缓存 |
| GitHub 请求失败被当作空结果；所有抓取来源失败后仍记录“刷新完成” | 在线搜索失败返回 502；所有来源失败时记录刷新错误，保留上次成功时间；其他来源可用时继续保存其结果 |

推荐生成期间会释放数据库读取连接，缓存替换使用事务和批量写入。此次业务代码变更集中在 `app/scraper.py` 与 `app/routers/projects.py`。

## 后续值得优化的方向

以下为后续建议，尚未实施。

| 优先级 | 建议 | 依据与收益 |
| --- | --- | --- |
| 高 | 补全已有项目的更新时间 | 当前有 74 个项目没有 `last_updated`。Trending 本身不提供该字段，不能把所有缺失都归因于本次修复的问题。可对缺失项目进行限速元数据补全，改善活跃度评分和“最近更新”排序；此次修复只防止继续覆盖，不会自动恢复历史缺失值 |
| 高 | 完善前端后台更新同步 | `app.js` 的状态签名只比较数量和刷新布尔值。页面隐藏期间完成的更新，或用户正在阅读时跳过的更新，可能未反映到列表。建议加入抓取版本或完成时间，保留待更新标记，在阅读结束后同步。此项来自代码检查，尚未进行浏览器复现 |
| 中 | 统一项目序列化和数据库连接管理，继续拆分页面逻辑 | 项目列表与收藏列表分别维护字段映射；`app.js` 约 900 行，仍集中处理多个功能。统一字段转换、连接释放和按功能划分状态逻辑，可减少后续变更时的遗漏 |
| 按规模推进 | 为高频查询补充索引，再评估全文检索 | 默认综合排序和最近抓取时间查询均出现全表扫描与临时排序；可优先评估 `(score DESC, id DESC)` 和 `fetched_at` 索引。当前数据量下查询成本很低，应结合增长后的测量决定优先级 |

只读 SQLite 测量中，默认列表查询约 0.21 ms，最近抓取时间查询约 0.03 ms。这是本机热缓存下每组 100 次、重复 5 组的每次查询耗时中位数，不代表完整 API 延迟或并发负载表现。

维护方面，建议将 Python 与 Node 检查接入 CI，并把 `docs/design.md` 视为历史设计资料；其中部分模型、端口和功能描述已与当前实现不同，当前使用方式以 README 和配置为准。
